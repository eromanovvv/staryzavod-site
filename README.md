# Старый завод — новый сайт пивоварни

Аудит старых сайтов, весь их контент, концепция и рабочий прототип нового сайта
пивоварни «Старый завод» (Спасский район, Рязанская область) и её бара Alter Brauch (Рязань).

Цель нового сайта — рост дистрибуции и продаж пива: главный посетитель — владелец магазина
разливного пива, ресторатор или закупщик сети, а не только любитель пива.

## Структура

```
research/
  ANALYSIS.md            аудит обоих сайтов, аудитории, позиционирование, структура нового сайта, план
  content/
    products.json        14 позиций с OG/Alc/IBU и описаниями (со страницы «Продукция»)
    points_of_sale.json  182 адреса точек продаж по сетям (со страницы «Точки продажи»)
    news.json, news.md   все 253 новости обоих сайтов 2015–2023 с датами и текстом
  raw/
    zavod/               239 HTML-страниц старыйзавод.рф (главная, разделы, все новости)
    alter/               57 HTML-страниц alter-brauch.ru + menu.pdf
    zavod_text.json, alter_text.json   извлечённый текст всех страниц
  assets/
    products/            оригинальные фото бутылок (16) и линейки
    site/                логотипы, фото цеха, завода, бара, исторические снимки, экскурсии
    menu/                7 страниц меню бара в PNG

site/                    прототип нового сайта (статика, без сборщика)
  index.html             главная: оффер для бизнеса, каталог, доверие, бар, где купить, история, форма
  beer.html              каталог с фильтрами и таблицей параметров
  business.html          для бизнеса: 3 сценария (магазин / HoReCa / сети), шаги, форма
  where-to-buy.html      182 адреса с поиском и фильтром по городу, место под Яндекс.Карту
  about.html             история 1911 → сегодня, технология, награды, экскурсии
  bar.html               бар Alter Brauch: краны, кухня, события
  contacts.html          контакты и форма
  data/products.json     данные каталога (правятся без вёрстки)
  data/points.json       точки продаж
  src/pages/*.html       исходники страниц (без шапки/подвала)
  src/partials/          head, header, footer
  build.py               склеивает partials + pages -> *.html
  assets/css/style.css   стили; assets/js/main.js — 18+, меню, каталог, точки, форма
```

## Запуск прототипа

```bash
cd site
python3 build.py            # после правок в src/
python3 -m http.server 8765 # http://localhost:8765
```

Никаких зависимостей: HTML + CSS + ванильный JS. Шрифты подгружаются с Google Fonts
(Playfair Display + Manrope); для продакшена в России лучше положить их локально.

## Что подключить перед запуском

1. **Форма заявки.** Сейчас `main.js` только показывает «спасибо» и пишет заявку в консоль.
   Варианты: Telegram-бот через небольшой прокси (Cloudflare Worker / Yandex Cloud Function),
   Formspree, Yandex Forms, PHP-обработчик на хостинге.
2. **Карта на «Где купить».** Яндекс.Карты JS API (бесплатно до 25 000 запросов/сутки):
   геокодировать адреса из `data/points.json` один раз, сохранить координаты в JSON.
3. **Данные от Васи.** Чек-лист в `research/ANALYSIS.md`, §5. В прототипе места, где нужны
   его данные, отмечены жёлтыми плашками «⚠ Уточнить у Васи».
4. **Метрика и цели.** Яндекс.Метрика (у старого сайта счётчик 43087379), цели: отправка формы,
   клик по телефону, переход в бар.
5. **Домен.** Оставить старыйзавод.рф как редирект; проверить, кому принадлежит stariyzavod.ru.

## Юридическое

Реклама алкоголя в интернете запрещена (ФЗ-38, ст. 21). Сайт производителя может информировать
о продукции, но без призывов купить, акций и скидок на алкоголь. В прототипе есть возрастное
подтверждение и дисклеймер в подвале; акции бара на сайт пивоварни не переносились.
